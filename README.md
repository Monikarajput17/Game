# Clue & Guess

Real-time multiplayer party game for 2–8 players.

## Run locally

1. Install Node.js 20 or newer.
2. Open a terminal in this folder.
3. Run `npm start`.
4. Open `http://localhost:3000`.

To test on multiple devices connected to the same Wi-Fi, open `http://YOUR-COMPUTER-IP:3000` on each device. Allow Node.js through the firewall if prompted.

No package installation is required.
